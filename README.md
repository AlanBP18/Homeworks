# Homeworks - Árbol de Gatos

Este proyecto es un visualizador de una estructura de datos tipo Árbol General, utilizando React, TypeScript y React Router.

## Cómo iniciar el proyecto

Sigue estos pasos para ejecutar la aplicación en tu entorno local:

1. **Entrar a la carpeta del proyecto:**

   ```bash
   cd HomeW
   ```

2. **Instalar las dependencias:**

   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**

   ```bash
   npm run dev
   ```

4. **Ver la aplicación:**
   Abre tu navegador en `http://localhost:5173`.

---

> [!IMPORTANT]
> **Aviso:** Para visualizar los algoritmos de ordenamiento y recorridos del árbol (DFS y BFS), dar click en la opción **Render** en el menú lateral derecho de la aplicación.
