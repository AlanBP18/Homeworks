# Tarea de Listas (Soundi)

Este proyecto es una tarea para la clase de Estructuras de Datos.

## ¿Qué contiene?
1. **Music Player**: Una lista de canciones que usa una **Lista Simple Enlazada**. Las canciones pasan una tras otra.
2. **Browser History**: Un simulador de historial de internet que usa una **Lista Doblemente Enlazada**. Puedes ir hacia atrás y hacia adelante entre las páginas.

## Cómo correrlo
1. Instalar dependencias: `npm install`
2. Correr el proyecto: `npm run dev`
