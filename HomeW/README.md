# Dashboard de Proyectos (Homeworks)

Este repositorio contiene una aplicación web construida con React (usando Vite), configurada con TypeScript, Bootstrap, SASS y Firebase Authentication.

## 🔥 Cómo Iniciar el Proyecto

Para hacer funcionar la aplicación en tu computadora local, debes tener **Node.js** instalado. Sigue estos simples pasos en tu terminal (en la misma carpeta donde está este archivo):

1. **Instala las dependencias**:
   ```bash
   npm install
   ```

2. **Inicia el servidor de desarrollo**:
   ```bash
   npm run dev
   ```

3. **Abre el proyecto**:
   Vite generará un enlace automático en tu terminal. Simplemente haz _Click_ o cópialo en tu navegador. Por lo general suele ser:
   `http://localhost:5173/`

¡Y listo! Al ser redirigido, podrás interactuar con la pantalla de inicio de sesión o acceder directamente a tu área de trabajos (Task App, Biblioteca o Cajero) una vez inicies sesión.
